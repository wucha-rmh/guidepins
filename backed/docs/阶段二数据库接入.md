# 阶段二数据库接入

以下 SQL 由你在 DBX 中执行。当前阶段不会自动修改远程库、创建远程登录角色或修改本地真实 `.env`。

## 1. 顺序和前置检查

全程连接目标数据库 **`guidepins`**，使用表所有者 `postgres` 或有创建角色及授权权限的维护账号。不需要切换维护数据库，不需要开启自动提交；授权段使用显式事务。

先执行以下只读 SQL：

```sql
SELECT current_database() AS database_name;

SELECT column_name, data_type, is_nullable, column_default
FROM information_schema.columns
WHERE table_schema = 'public' AND table_name = 'user_account'
ORDER BY ordinal_position;

SELECT rolname, rolsuper, rolcreatedb, rolcreaterole, rolcanlogin
FROM pg_roles
WHERE rolname IN ('guidepins_agent', 'guidepins_app');
```

账号表应已有 `avatar_path text` 和 `status smallint NOT NULL DEFAULT 1`；`role` 默认值为 `'user'`。如果缺少新增字段，先按[账号头像与状态增量迁移](../../docs/技术/账号头像与状态增量迁移.md)完成迁移，再继续本文件。不要重跑已完成的建表和管理员初始化脚本。

## 2. 创建专用运行账号并授予最小权限

**目标数据库：`guidepins`，维护账号连接，整段执行。** 执行前只替换 `app_password` 的字符串内容为独立强密码；如果密码包含单引号，SQL 中用两个单引号表示。不要把填写了真实密码的脚本提交 Git。

脚本遇到错误会中止事务，先执行 `ROLLBACK;` 再处理原因。若 `guidepins_app` 已存在，脚本会拒绝继续，先核对其已有权限和用途，避免覆盖其他账号设置。

```sql
BEGIN;

DO $$
DECLARE
    app_password text := '替换为你生成的独立强密码';
BEGIN
    IF current_database() <> 'guidepins' THEN
        RAISE EXCEPTION '请切换连接到 guidepins 数据库';
    END IF;
    IF app_password = '替换为你生成的独立强密码' OR char_length(app_password) < 20 THEN
        RAISE EXCEPTION '请先填写至少 20 个字符的独立应用数据库密码';
    END IF;
    IF NOT EXISTS (
        SELECT 1 FROM information_schema.columns
        WHERE table_schema = 'public' AND table_name = 'user_account'
          AND column_name = 'status' AND data_type = 'smallint'
    ) OR NOT EXISTS (
        SELECT 1 FROM information_schema.columns
        WHERE table_schema = 'public' AND table_name = 'user_account'
          AND column_name = 'avatar_path'
    ) THEN
        RAISE EXCEPTION '请先完成账号头像与状态增量迁移';
    END IF;
    IF EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'guidepins_app') THEN
        RAISE EXCEPTION 'guidepins_app 已存在，请先核对用途及权限，不重复创建';
    END IF;
    EXECUTE format(
        'CREATE ROLE guidepins_app LOGIN NOSUPERUSER NOCREATEDB NOCREATEROLE NOREPLICATION NOBYPASSRLS NOINHERIT PASSWORD %L',
        app_password
    );
END;
$$;

GRANT CONNECT ON DATABASE guidepins TO guidepins_app;
GRANT USAGE ON SCHEMA public TO guidepins_app;
GRANT SELECT ON TABLE public.city, public.user_account, public.auth_session,
    public.travel_map, public.map_pin TO guidepins_app;

-- 注册只写这三个字段；角色、正常状态、创建时间及 UUID 使用已有数据库默认值。
GRANT INSERT (email, phone, password_hash)
    ON TABLE public.user_account TO guidepins_app;

-- 登录创建会话；退出和定时清理删除会话，不需要 UPDATE 权限。
GRANT INSERT (token_hash, user_id, created_at, expires_at), DELETE
    ON TABLE public.auth_session TO guidepins_app;

-- 阶段二仅创建地图并修改名称、可见性及最近更新时间。
GRANT INSERT (city_id, owner_id, name, visibility),
    UPDATE (name, visibility, updated_at)
    ON TABLE public.travel_map TO guidepins_app;

COMMIT;
```

这里不新建表或字段，因此没有新增字段注释。已有字段的用途和 `COMMENT ON COLUMN` 见数据库说明与增量迁移。UUID 默认函数不使用序列，因此不需要序列授权。没有为地市、图钉开放写权限，也没有授予修改账号角色／状态、地图所有者／创建时间或删除地图的权限。

## 3. 只读核对授权

**目标数据库仍为 `guidepins`，维护账号或读取账号执行。** 以下结果应全部为 `true`。

```sql
SELECT
    has_database_privilege('guidepins_app', 'guidepins', 'CONNECT') AS can_connect,
    has_schema_privilege('guidepins_app', 'public', 'USAGE') AS can_use_schema,
    has_table_privilege('guidepins_app', 'public.city', 'SELECT') AS can_read_cities,
    has_table_privilege('guidepins_app', 'public.map_pin', 'SELECT') AS can_read_pins,
    has_column_privilege('guidepins_app', 'public.user_account', 'email', 'INSERT') AS can_register,
    has_column_privilege('guidepins_app', 'public.auth_session', 'token_hash', 'INSERT') AS can_create_session,
    has_table_privilege('guidepins_app', 'public.auth_session', 'DELETE') AS can_remove_session,
    has_column_privilege('guidepins_app', 'public.travel_map', 'owner_id', 'INSERT') AS can_create_map,
    has_column_privilege('guidepins_app', 'public.travel_map', 'name', 'UPDATE') AS can_rename,
    has_column_privilege('guidepins_app', 'public.travel_map', 'visibility', 'UPDATE') AS can_change_visibility,
    has_column_privilege('guidepins_app', 'public.travel_map', 'updated_at', 'UPDATE') AS can_update_time;

SELECT
    NOT has_column_privilege('guidepins_app', 'public.user_account', 'role', 'INSERT') AS cannot_insert_role,
    NOT has_column_privilege('guidepins_app', 'public.user_account', 'role', 'UPDATE') AS cannot_change_role,
    NOT has_column_privilege('guidepins_app', 'public.user_account', 'status', 'UPDATE') AS cannot_change_status,
    NOT has_column_privilege('guidepins_app', 'public.travel_map', 'owner_id', 'UPDATE') AS cannot_transfer_map,
    NOT has_column_privilege('guidepins_app', 'public.travel_map', 'created_at', 'UPDATE') AS cannot_change_created_time,
    NOT has_table_privilege('guidepins_app', 'public.travel_map', 'DELETE') AS cannot_delete_map,
    NOT has_any_column_privilege('guidepins_app', 'public.city', 'UPDATE') AS cannot_update_city,
    NOT has_any_column_privilege('guidepins_app', 'public.map_pin', 'INSERT') AS cannot_create_pin;
```

业务用户的地图权限由后端与 SQL 校验；数据库应用账号能够服务多个用户，不按每个网站账号建立 PostgreSQL 登录角色。

## 4. 切换后端配置

只把 `backed/.env` 中的数据库用户名和密码改为新运行账号；数据库地址保持实际连接值。`guidepins_agent` 继续用于只读核查。重启后端后，先核对访客读取和底图，再验证注册登录及两账号隔离。

本机验证脚本另建临时 PostgreSQL，采用相同列级授权；它不证明远程授权已经执行，也不证明远程已有管理员的真实密码已验证。
