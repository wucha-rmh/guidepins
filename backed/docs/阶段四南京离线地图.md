# 阶段四第 1 小步：南京地图下载与离线浏览

交付日期：2026-11-26（北京时间）。本轮只覆盖南京，开发侧交付，待用户验收。

## 用户怎么用

1. 在网站打开南京的一张公共地图，或登录后打开自己的私人地图。
2. 在侧栏底部点击「下载离线地图」，等待浏览器保存 `.html` 文件。
3. 用较新版本的 Windows Edge 或 Chrome 双击打开文件。无需安装软件、启动本机服务或重新选择底图。
4. 断网后仍可拖动、缩放、选择地点、查看说明和攻略；攻略中的地点按保存时的站序排列，点击可定位。

本机可直接打开[南京离线演示样包](../../docs/验收/阶段四-南京离线样包.html)，其中三个地点和攻略均为隔离测试数据整理的示例。截图：[街区视图](../../docs/验收/阶段四-南京离线街区.png)、[全市视图](../../docs/验收/阶段四-南京离线全市.png)、[网站下载入口](../../docs/验收/阶段四-南京下载入口.png)。样包与截图保存在被 Git 忽略的本机附件目录，迁移工作区时需另行保存。

这是下载时的只读快照，后续网站编辑不会自动同步。出处正文随包保存；「查看出处原文」需要联网。修改地图公开状态只影响之后的网站读取和下载，已经保存的文件不撤回。

## 为什么没有下载整份南京底图

- 全市保留 z7～12 的概况瓦片，包含数据中已有的道路、水系、绿地、地铁等。
- 每个图钉按南北、东西各约 2 公里的范围提取 z13～16 详细瓦片。范围按瓦片边界向外覆盖；覆盖交叠或内容相同的瓦片只保存一份。
- 查看器用两份瓦片来源叠加显示。地点周边可看建筑等细节，范围外继续放大全市概况，不请求网络补图。
- 虚线显示实际保存的 z16 详细瓦片外边界。空地图仅包含全市简图。
- 瓦片索引、地图内容和查看器脚本经过压缩后内置在文件中，中文标注使用本机字体。

当前南京底图为 35,635,446 字节（已更新地铁单线和 z12 起的站点）。夫子庙、新街口、玄武湖三地点样包约 **7.4 MB**，比原始底图小约 **79.2%**；无图钉样包约 **5.0 MB**。样包大小取决于地点数量与分布，这些数值不代表所有地图的固定大小。

地铁在离线版只从全市来源绘制一次，避免简图与详细来源叠出双线或重复站点；站点使用用户确认的蓝灰圆角车头图标，资源随查看器内置。南京 257 个站点已逐站验证在 z12、z14、z16 的瓦片中存在。S2 源轨道仍有不完整部分，保留已有数据，不补造线路；详细调整见[前端验收记录](../../frontend/验收记录.md)。

## 模块边界

| 位置 | 职责 |
| --- | --- |
| `backed/src/main/java/com/guidepins/offline/domain` | 版本化的快照契约，不包含账号和会话信息 |
| `offline/service/OfflineSnapshotService` | 在短只读、可重复读事务中检查地图读取权限并取得地图、图钉、攻略、站序 |
| `offline/mapper/PmtilesExtractor` | 读取本机 PMTiles v3 目录，按缩放和地点范围提取、去重瓦片 |
| `offline/service/OfflineExportService` | 在数据库事务结束后裁剪底图并生成自包含 HTML；最多同时生成两份文件，不共享缓存私人内容 |
| `offline/controller/OfflineExportController` | 返回附件和禁止缓存响应头，错误仍使用统一 JSON |
| `frontend/offline` | 独立查看器、样式及打包脚本；复用现有底图样式，绘图 Worker 一并打包 |
| `frontend/src/api/offline.ts` | 下载请求及错误解析 |
| `frontend/src/composables/useOfflineDownload.ts` | 超时、禁止重复下载、切图及身份变化时取消并丢弃旧结果 |
| `frontend/src/components/OfflineDownloadPanel.vue` | 南京地图下载入口与提示 |

新增独立离线模块是为了把在线编辑、权限读取和文件生成分开，避免下载逻辑继续扩充地图编辑服务。数据库结构、现有业务数据与运行时依赖没有变化。

## 接口

`GET /api/maps/{mapId}/offline`

- 公共地图允许访客下载；私人地图仅所有者可下载，非所有者管理员同样不可访问。
- 不存在或无读取权限返回 404；非南京地图返回 400；地点范围或瓦片总量超限返回 413；查看器、底图未就绪或生成繁忙返回 503。
- 成功返回 `text/html; charset=UTF-8`，`Content-Disposition: attachment`、`Cache-Control: no-store` 和文件长度。响应不会被包装成 JSON。
- 快照版本为 1，包含地图编号、名称、地图更新时间、导出时间、城市、图钉和攻略及站序。没有密码、令牌、邮箱或手机号。
- 导出不改变地图更新时间。前端最多等待 120 秒，不自动重试；退出、切图或身份检查变化后不保存迟到文件。

## 构建和运行

前端构建会同时生成后端要使用的离线查看器模板：

```powershell
# 在 D:\GuidePins\frontend 执行
npm run build

# 然后在 D:\GuidePins\backed 执行
mvn verify
```

只重建离线查看器时，在前端执行 `npm run build:offline`。模板生成到 `backed/target/offline-assets/offline/viewer.html`，Maven 将其复制到类路径并打进 JAR。没有把生成的脚本或地图二进制提交到源码。

`mvn clean` 会移除生成模板；使用 clean 时，应先 clean，再构建前端，最后构建后端。没有构建模板时在线功能仍可使用，下载接口会明确返回 503。部署需要使用包含新模板的后端 JAR，并保留现有南京 PMTiles 文件。

## 集中验证

- 前端类型检查、查看器构建及生产构建通过；在线地图分包原有的 500 kB 提示仍存在。
- 独立本机 PostgreSQL、最小授权应用账号上的完整 Maven 验证为 **40 项全部通过，无跳过**。
- 新增提取测试覆盖独立 Hilbert 编号、gzip 叶目录、近处／远处瓦片选择、重复地点去重、无图钉及损坏／不支持的归档。
- 新增下载集成测试覆盖访客公共下载、私人所有者下载、其他账号和管理员拒绝、公开改私人、非南京拒绝、非法编号、地图时间不变、攻略内容与站序、账号数据排除和文本注入边界。
- 浏览器使用真实 JAR、生产预览、真实南京 PMTiles 及独立本机库。网站下载、双击只发一次请求、503 反馈，以及关图／退出后丢弃迟到私人文件均验证。
- Edge、Chrome 在断网浏览器上下文中通过 `file://` 直接打开、重新加载、地点与攻略联动和空地图；未观察到外部 HTTP 请求、页面脚本异常或控制台错误。
- 截图集中核对街区细节与全市视图。离线全市适配允许市界外留白，避免严格边界约束裁掉南京南北两端。

复现方式：先按上文构建，然后使用已有隔离库脚本运行后端测试，再运行浏览器脚本。集成测试默认用人工最小归档；设置 `GUIDEPINS_OFFLINE_REAL_BASEMAP_ROOT` 为本机城市底图目录，可在集成测试中验证真实底图。浏览器脚本使用仓库已有的真实南京底图。

```powershell
# 在 D:\GuidePins\backed 执行；工具需位于 PATH 中
.\tools\verify-stage-two.ps1

# 在 D:\GuidePins 执行；需要 Python playwright、PostgreSQL 工具和本机 Edge、Chrome
python backed/tools/verify-offline-browser.py
```

脚本不会读取 `.env` 或连接业务库；服务均使用独立本机端口，完成后停止自己启动的进程。原始结果、样包和截图保存在 `backed/target/offline-browser-*`，不会提交。

## 验收边界

本轮只验收南京、Windows Edge／Chrome、只读快照。第二座城市、移动端浏览器、离线编辑和同步后续另议。图钉很多或分布广时文件会增大；详细底图范围外只有概况。真实业务环境需重启更新后的后端后再验收，本机临时库结果不等同于远程业务库联调。
