# 拾点地图 · PC 前端

提供城市与公共地图浏览，以及注册登录、创建私人地图和地图元数据管理。沿用城市手帐界面、UI2 首页及 UI3 城市漫游底图；基础功能见[阶段二前端验收记录](阶段二前端验收记录.md)，入口调整见[个人中心与侧栏收纳验收记录](个人中心与侧栏收纳验收记录.md)，最新调整见[手机号区号选择验收记录](手机号区号选择验收记录.md)，历史验证见[验收记录](验收记录.md)。

## 运行与配置

需要 Node.js 22.12 及以上版本。先按[后端说明](../backed/README.md)开启数据库隧道并启动后端，再运行：

```powershell
cd D:\GuidePins\frontend
npm ci
npm run dev
```

访问 [本地前端](http://127.0.0.1:5173/)。端口占用时运行 `npm run dev -- --port 5174`。

默认后端为 `http://127.0.0.1:8080`。需要更换时，将 `.env.example` 复制为 `.env`，设置 `GUIDEPINS_BACKEND_URL` 后重启前端；保留已有配置，前端无需数据库凭据。

```powershell
npm run typecheck   # 类型检查
npm run build       # 类型检查并构建到 dist
npm run preview     # 预览构建，默认端口 4173
```

开发与预览均代理 `/api`、`/maps`。生产服务器需提供同源代理并保留 Range／206 响应，地图 Worker 的 `.mjs` 文件须以 JavaScript 类型返回；Vite 代理配置不进入构建产物。

## 模块职责

| 位置 | 职责 |
| --- | --- |
| `src/app` | 导航、Hash 路由、页面组合与样式；地图页持有图钉选中和侧栏收纳状态，组合层转交个人地图导航意图 |
| `src/modules/city` | 城市目录契约、请求、加载状态与选择页 |
| `src/modules/public-map` | 公共地图和地点的请求、状态、列表与详情 |
| `src/modules/auth` | 注册登录请求、共享内存身份、会话恢复与退出、统一认证页、圆形个人中心菜单 |
| `src/modules/map-management` | 个人地图列表、创建、改名、公开状态及管理记录展示 |
| `src/modules/pin-editing` | 编辑模式下点地图落钉、拖动草稿圆环改坐标、侧栏改名称与说明、二次确认删除 |
| `src/modules/guide-editing` | 攻略录入（标题、正文、来源链接）、拖动或箭头调整「提到的地点」站序、删除确认与只读展开 |
| `src/modules/basemap` | MapLibre／PMTiles 生命周期；`style.ts` 管底图，`views.ts` 管观察点，`pinLayers.ts` 管图钉与气泡 |
| `src/shared/StatePanel.vue` | 共用加载、空数据、失败及重试提示 |
| `src/shared/apiResponse.ts` | 校验后端统一的 `code`、`message`、`data`，解包业务数据并展示接口错误信息 |
| `src/shared/apiRequest.ts` | 新增 JSON 接口的同源 Cookie 请求、CSRF 获取、15 秒超时及取消；写请求不自动重放 |

各业务模块内，`api.ts` 负责请求和数据校验，组合函数负责状态，Vue 组件负责展示与交互。

地市、公共地图列表和详情接口使用 `{code, message, data}`，`code` 必须与 HTTP 状态一致；各模块在解包后继续校验业务数据。资源不存在／地址无效仍使用原有返回入口提示，底图与市界静态资源沿用各自格式。

## 路由与主要行为

| Hash 路径 | 页面 |
| --- | --- |
| `/#/` | 城市目录 |
| `/#/auth` | 统一登录注册页，默认登录，`?mode=register` 切换注册 |
| `/#/login`、`/#/register` | 兼容旧地址，保留参数并跳转到统一认证页对应模式 |
| `/#/?tab=mine` | 先选择城市，再进入该城市的我的地图 |
| `/#/cities/:cityId` | 城市底图与公共地图列表 |
| `/#/cities/:cityId?tab=mine` | 当前城市的我的地图与私人地图创建 |
| `/#/cities/:cityId/maps/:mapId` | 有权访问的地图、地点列表和图钉；可用 `?tab=mine` 保留个人列表 |
| 其他路径 | 不存在提示与返回入口 |

- 城市、地图和图钉来自接口，坐标为 WGS84，经度在前；地图选择以 URL 为准。刷新恢复资源，不恢复选中图钉或最后的拖动、缩放位置。
- 右上角统一为圆形个人中心入口。访客菜单提供“登录 / 注册”；登录后展示账号、角色、我的地图和退出。当前城市内直接打开个人列表，没有选城市时先回目录选择；菜单支持点击外部、Tab 移出及 Escape 关闭，Escape 返回入口焦点。
- 城市左侧面板默认展开，边缘按钮可收起／展开。收纳不卸载表单和详情，不重建地图；展开恢复滚动、草稿和选中图钉。切换城市或从个人菜单进入我的地图时展开面板；收纳状态不写入浏览器存储，刷新后默认展开。
- 进入城市先看主城区；“查看全市”适配城市边界。打开公共地图后适配图钉范围；点侧栏会飞到地点，点图钉只选中，点空白取消选中。
- 图钉按列表顺序编号，普通为深绿、选中为陶土橙；气泡可关闭或按 Escape 取消，长文本内部滚动，没有说明时不显示说明段落。
- 城市、地图列表及详情请求超时为 15 秒，底图为 20 秒。失败可重试；不存在或无效资源提供返回入口，详情所属城市也会校验。
- 底图按 Range 读取，离开页面释放资源。建筑在道路下方，标注按缩放分级；南京市界资源加载失败时保留可用底图，OpenStreetMap 署名始终保留。
- 登录和注册在同一页内切换，保留账号输入、清空密码与错误；注册仅提交邮箱或手机号中的一项。密码保留首尾空格，注册长度 6～128，登录兼容旧账号的短密码。注册成功同页切回登录，不自动登录；登录成功返回原城市／地图地址或个人地图选城入口。提交结束清空表单密码。
- 手机号采用“国家／地区码下拉框＋手机号”输入，默认中国 +86；切换登录／注册保留选择与号码。提交时组合为原接口完整号码，粘贴含所选区号且以 `+` 开头的完整号码时不重复拼接；区号不匹配、非数字或总长度超过 15 位时提示修正。区号配置在认证模块内，运行时不请求外部区号服务。
- 会话通过后端 HttpOnly Cookie 管理，浏览器存储不保存身份或令牌。启动、窗口重新获得焦点或页面重新可见时检查身份；详情等到检查结束后读取。身份变化时同步清除个人列表与详情，取消并忽略旧读取结果。
- 创建默认私人；所有者可改名、选择公开或私人并显式保存。公共列表同步更新，时间按北京时间显示。管理员可修改他人公共地图名称，不能切换他人公开状态或访问他人私人地图；权限最终由后端校验。
- 退出开始就移除私人内容，失败会提示“退出未确认”并提供重试。受保护请求返回 401 时清除身份；403 保留有效身份并显示后端提示。写请求失败不自动重试，超时后先刷新确认结果。
- 其他浏览器中发生的地图变更需要刷新后读取，不提供实时推送。私人地图不存在或不可见时保留底图和列表，访客可通过登录入口返回原地图。
- 有写权限时侧栏出现「编辑图钉」与「攻略与出处」：编辑模式下点地图落钉，按住草稿圆环拖动改坐标，改名称说明，删除需二次确认；攻略录入标题、正文与可选来源链接，「提到的地点」可拖动或按箭头调整站序，也允许先保存成没有地点关联的草稿。地点列表下方按「出处」列出提到它的攻略标题，点标题展开对应那一篇；点攻略里的地点名会飞到该钉。

## 当前限制

- 图钉与攻略写入已实现，收藏、手机端与离线快照尚未实现，PC 最小宽度为 1100px。
- 暂不验证邮箱／手机号，不支持找回密码、头像上传或账号管理。远程数据库增量与运行账号授权已在远程库执行，本轮后端验证使用独立本机数据库，不代表远程联调已完成。
- 目前仅接入南京，主城区观察点和市界资源也只配置了南京。
- 地图分包约 1.124MB，仍超过 500kB；密集图钉尚未压测，完全重叠的地点可通过侧栏选择。
