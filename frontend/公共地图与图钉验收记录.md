# 阶段一 · 第 2 小步：公共地图与图钉真实接入

验证时间：2026-11-23 18:30（北京时间）。

状态：**已实现并完成开发侧验证，待用户验收。** 阶段一访客主流程（选地市 → 看底图 → 开公共地图 → 看真实图钉与说明）已可整体验收。

## 本轮交付

- 新增公共地图模块的数据层：`types.ts` 定义公共地图、图钉与详情契约，`api.ts` 请求 GET /api/cities/{cityId}/maps 与 GET /api/maps/{mapId} 并校验响应，`useRemoteResource.ts` 统一处理加载、15 秒超时、取消旧请求、区分“不存在”与“请求失败”及重试。
- `usePublicMaps.ts`、`usePublicMapDetail.ts` 以 URL 中的地市 id、地图 id 为输入，id 变化时重新请求。
- 新增 `modules/basemap/pinLayers.ts`：图钉圆点、光晕、选中环三个圆点图层，点击命中判断与说明气泡；气泡内容用 DOM 文本写入，避免把接口文本当 HTML。
- `createBasemap.ts` 增加图钉图层的挂载与 `setPins`、`fitPins`、`flyToPin`，并向上报告图钉点击；视图销毁时一并移除图层与气泡。
- `BasemapViewport.vue` 接收图钉与选中 id，地图图钉与侧栏列表共享同一份选中状态。
- 改写 `PublicMapPanel.vue`、`MapDetailPanel.vue`、`MapPage.vue`：真实列表、当前地图标记、图钉条目与选中态、暂无图钉提示、各状态的失败与重试、未知地市与未知地图的返回入口。
- 删除骨架期的 `app/preview.ts` 与 `modules/public-map/preview.ts`，一并移除页面上的“默认 / 加载中 / 空数据 / 加载失败”预览工具及其样式。

| 列表超时 | 不响应的列表请求在 15 秒后显示「公共地图列表加载超时，请检查网络后重试。」与重试按钮 |

故障验证使用独立的 5174 前端与 8091 故障代理：代理只读转发真实 8080 后端，按场景返回 503、空数组、缺字段数据或不响应。代理源码保存在本地 [地市底图故障代理](../docs/验收/地市底图故障代理.mjs)（本轮扩展了公共地图与详情场景），按既有 docs 忽略规则不进入 Git。未修改数据库、地图文件，也未改动用户正在使用的 5173 与 8080。

浏览器验证通过 Chrome 无头实例配合 DevTools Protocol 脚本完成：脚本位于系统临时目录，不在仓库内，只用于本轮取值、点击与截图。

## 已发现并修复

- 地图详情的类型守卫最初直接访问 `value.pins`，类型检查报 `TS2339: Property 'pins' does not exist on type 'PublicMap'`；改为在确认是对象之后先取出 `pins` 再校验。
- 图钉不能使用文字图层：底图样式没有 glyphs，任何 `text-field` 都会触发地图错误并让整张图进入失败状态。说明文字改由 MapLibre Popup 与侧栏条目承担。
- 同一页面组件在 `/#/cities/:cityId` 与 `/#/cities/:cityId/maps/:mapId` 之间切换时，Vue 会复用实例而不重新挂载，因此列表与详情必须由 `watch(cityId)`、`watch(mapId)` 驱动加载。故障场景复现时确认了这一点，并用刷新页面重新拉取的方式验证了失败路径。
- 验收环境限制（非代码问题）：本机沙箱禁止 shell 删除或新建文件、禁止 Chrome 建立命名管道，因此删除骨架文件、启动 Vite 与无头浏览器验收各使用了一次性提升权限。

## 当前边界与待办

- 选中的图钉不写入 URL，刷新或直接打开地图地址不恢复上次的选择。
- 不提供图钉的新增、编辑、移动与删除，也不提供收藏或分享；这些属于阶段三。
- 只接入南京一个地市和一张示例公共地图，第二个地市的底图与切换待阶段四。
- 公共地图与图钉均为只读；当前没有可见性过滤与权限控制，待阶段二。
- 手机端未适配，PC 最小布局宽度 1100px。
- 构建仍提示地图分包超过 500 kB；地图页已按需加载，当前不阻碍本阶段验收。
- 本轮临时验收服务（5174、8091 与无头浏览器）在验证结束后停止；用户原有的 5173 服务保留。
