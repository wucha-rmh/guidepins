# 阶段一 · 第 1 小步：真实地市与南京底图

验证时间：2026-11-23 17:02（北京时间）。

状态：**已实现并完成开发侧验证，待用户验收。** 阶段一的公共地图与图钉真实接入尚未实施。

## 本轮交付

- 地市页读取 GET /api/cities，渲染真实目录；移除 preview-nanjing 示例地市。
- 根据 URL 中的地市 ID 从目录恢复当前地市，未知地市提供明确提示及返回入口。
- 使用接口 basemapPath 按 HTTP Range 读取 PMTiles，以 bounds 初始化南京视野。
- MapLibre 支持拖动、滚轮、按钮及键盘缩放，并提供查看全市按钮。
- 底图样式独立放在 src/modules/basemap/style.ts，沿用南京原型的道路、水系、建筑和标注配色。
- 地市请求和底图各自管理加载、失败、超时及重试；离开页面、超时与重试时取消旧请求并释放地图资源。
- 开发及生产预览的 /api、/maps 同源代理，支持配置后端地址。
- 公共地图与详情仍为骨架示例，预览状态仅影响该模块。

## 已发现并修复

- MapLibre 6 默认 Worker 相对路径在 Vite 依赖预构建后失效：显式导入 Worker URL，由 Vite 输出独立资源。
- MapLibre 默认容器样式覆盖画布定位，导致容器高度为零：提高容器规则的选择器优先级，并明确宽高。
- 将地图页面改为按路由加载，避免地市入口提前加载完整地图引擎。
- PMTiles 头部请求补充生命周期取消，确保超时、重试和退出地图后可以中断悬挂读取。
