# 阶段一 · 底图样式对齐 V2「城区细节版」

验证时间：2026-11-23 18:52（北京时间）。

状态：**已实现并完成开发侧验证，待用户验收。** 样式参照 `map/南京全市离线地图/nanjing-city-map-v2.html`（`map/样式版本记录.md` 中的 V2，当前采用版）。

## 本轮交付

- 重写 `modules/basemap/style.ts`，按 V2 的 `mapStyle()` 落地：背景 #f5f3ee、绿地 #dce8d5（0.96）、水面 #b8dce8、溪流 #a8cfdf；建筑 #cec8bc 描边 #ada697，不透明度按 14 → 15.5 → 17 升到 0.58 / 0.84 / 0.94；道路拆成路底与路面两层，主干道 #d5bd91 / #ecd09a、次干道 #f1dfb6、步道 #fdfaf4，宽度按道路等级加权。
- 绘制顺序改为“建筑在道路之下”，并补齐两类原型里有、前端此前缺失的标注：建筑名（级别 15 起，仅数据里有非空名称的建筑）、按等级分字号的地名（城市 / 城镇 / 其他，博物馆用暖棕 #8c6848），道路名起点从级别 15 提前到 13，间距 250。
- 新增 `modules/basemap/nanjing-boundary.json`（523 KB，由 `map/南京全市离线地图/nanjing-boundary.js` 转出）与样式里的 `cityLimit` 数据源、`outside-city` 遮罩层、`city-outline` 市界线；数据在底图就绪后异步补入，取不到时只丢遮罩，不影响底图。
- 新增 `modules/basemap/views.ts`：按城市 code 配置主城区观察点，南京取新街口一带 `[118.79, 32.055]` / 级别 14.2；未配置的地市退回行政区范围中心、级别 13。
- `createBasemap.ts`：初始视野改为主城区（不再用 bounds 首屏），新增 `fitUrban()`，保留 `fitCity()`；级别读数改为在 `zoom` 与 `moveend` 时都上报，动画过程中即时刷新。
- 地图错误处理放宽一处：缺字形的报错不再让整幅底图进入失败态（样式没有 glyphs，个别英文或数字标注可能缺字形），只有真正的加载失败、404 与 WebGL 中断才显示失败面板。
- `BasemapViewport.vue` 的按钮区改为「主城区」「查看全市」两个按钮；`styles.css` 换成 `.map-view-actions` 容器与 V2 底色，避免首屏闪烁暖色。`MapPage.vue` 侧栏提示同步改成两个按钮的用法。

## 已发现并修复

- `hasName` 过滤器最初写成 `as const`，`FilterSpecification` 不接受只读元组，类型检查报 `TS2322: Type 'readonly [...]' is not assignable to type 'FilterSpecification | undefined'`；改为显式标注 `FilterSpecification`。
- 原型里「查看全市」与「主城区」是并列按钮，首屏改为主城区后，侧栏提示仍写着“点击查看全市回到初始范围”，指向错误；已改成分别说明两个按钮。
- 市界数据若直接内联进 JS 会把地图分包再撑大 500 KB，因此改为独立资源 + 就绪后 `setData`，失败时静默降级为无遮罩。

## 当前边界

- 只有南京配置了主城区观察点；接入第二个地市时需要在该城市补一条，否则首屏落在行政区中心、级别 13。
- 市界遮罩只有南京一份数据，未按城市拆分；多城市阶段需要改成按城市加载。
- 只在 1280 × 800 视口下验证；更窄的窗口（最小支持 1100px）与更高缩放级别未逐一截图核对。
- 建筑名依赖地图包内的建筑名称字段，不是所有建筑都有名字，出现密度会随瓦片数据变化。
- V2 原型里的“点击建筑查看详情”没有搬过来：本阶段的点击交互仍只服务图钉。
- 遮罩资源加载失败的降级路径只做了代码检查，没有在浏览器里制造 404 实测。
