# 阶段二前端：登录与私人地图

日期：2026-11-24（北京时间）。开发侧实现和集中验证完成，用户验收待确认，未提交 Git。

本页记录阶段二初始交付。后续登录注册合页、圆形个人菜单及地图侧栏收纳的范围和最新结果见[个人中心与侧栏收纳验收记录](个人中心与侧栏收纳验收记录.md)。

## 交付

- 邮箱／手机号注册登录、注册后转登录、内存身份与 Cookie 会话恢复、退出，以及原地图地址回跳。
- 城市内公共地图／我的地图分类、默认私人创建、自动打开新地图、名称修改、公开／私人状态切换。
- 本人地图创建与更新时间展示，时间转换为北京时间；列表排序与后端一致。
- 普通用户对他人公共地图只读；管理员可改他人公共地图名称，无切换他人公开状态的入口；他人私人地图不可访问。
- 统一响应解包与业务校验、同源 Cookie、逐次获取 CSRF、超时和错误反馈、禁止自动重放写请求。
- 退出开始、身份改变、会话过期或恢复失败时清除私人列表和详情，取消并忽略旧读取结果；保留城市底图和可用导航。

## 模块与职责

| 模块 | 职责 |
| --- | --- |
| `auth/api.ts`、`types.ts` | 认证契约、请求和身份响应校验 |
| `auth/useAuth.ts` | 全站共享身份、会话恢复、退出、并发恢复去重和旧结果隔离 |
| `auth/AuthPage.vue` | 注册／登录输入、校验、结果反馈与应用内回跳 |
| `map-management/api.ts`、`types.ts` | 地图管理契约、请求校验、名称规则与时间展示 |
| `map-management/useOwnedMaps.ts` | 以城市和身份为边界的个人列表状态、读取取消及写入结果合并 |
| `map-management/MyMapsPanel.vue` | 创建表单、本人列表与读取反馈 |
| `map-management/MapSettingsPanel.vue` | 名称、公开状态、元数据与写入反馈 |
| `app` | 导航、路由、列表分类、权限入口和模块组合 |
| `shared/apiResponse.ts`、`apiRequest.ts` | 响应外层与带状态码错误、同源请求、CSRF 和超时 |

没有引入状态管理、UI 或测试框架依赖，没有改动后端业务源码、数据库结构或真实业务数据。

## 验证环境与方法

1. 执行 `npm run build`，包含 `vue-tsc --noEmit` 与 Vite 生产构建。
2. 创建仅监听 `127.0.0.1` 的独立 PostgreSQL 18.6 临时实例，数据库固定为 `guidepins_frontend_test`。使用仓库现有测试建表文件和最小授权应用账号运行真实后端 JAR。
3. 使用构建预览、真实后端、南京 PMTiles 和 Edge 无头浏览器，建立互相独立的两个普通账号、管理员及访客浏览器上下文。
4. 注册、登录、创建、改名、状态切换及权限拒绝调用真实接口。管理员角色与样例图钉只在隔离库中准备；故障及延迟响应通过测试浏览器路由拦截模拟。
5. 脚本、日志和结果保存在被 Git 忽略的 `backed/target/frontend-stage-two`。没有读取本地 `.env`，没有连接远程业务库。

## 结果

生产构建通过。浏览器主流程 14 组、补充边界 7 组，共 21 组通过。

| 验证范围 | 结果 |
| --- | --- |
| 访客入口与个人列表 | 城市可浏览，我的地图引导登录 |
| 邮箱注册登录 | 邮箱规范化、注册不自动登录、密码清空、登录回到原城市通过 |
| 手机号注册登录 | 带国家码注册登录、独立身份通过 |
| 私人地图创建 | 默认私人、直接打开、初始时间相等、名称纯文本显示通过 |
| 刷新与地点浏览 | Cookie 身份、私人地图、真实图钉及气泡联动恢复通过 |
| 改名与时间 | 空白名称拒绝，成功后列表与标题同步，更新时间推进 |
| 两账号隔离 | 我的地图只含本人数据，私人直链互相拒绝，访客也不可读 |
| 公开与普通用户权限 | 公开后访客刷新可读，普通账号不可改他人公共地图 |
| 管理员权限 | 可改他人公共地图名称，无他人状态切换入口；真实接口拒绝越权状态修改及他人私人详情 |
| 改回私人 | 访客、另一普通账号和非所有者管理员刷新后读取均被拒绝 |
| 退出及再次登录 | 私人列表、图钉和气泡清空；从私人直链登录可回到原地图 |
| 会话与 CSRF | HttpOnly 会话、浏览器存储无令牌；缺少 CSRF 的真实写请求为 403，登录／退出后的连续写入正常 |
| 会话失效 | 服务端删除隔离测试会话后，写请求 401 清除身份与私人内容 |
| 原有读取与布局 | 后端错误 message 展示及重试恢复；1100／1280／1440 宽度无横向溢出，Range 请求 206、127 字节返回；主流程无页面脚本异常 |
| 迟到的私人详情 | 请求被延迟、期间退出、旧响应随后返回，不恢复私人内容 |
| 写入超时与防重复 | 双击创建只发一次请求，15 秒超时提示先确认结果，不自动重放 |
| 个人列表格式错误 | 拒绝无效业务数据、清空旧列表，重试可恢复 |
| 403 反馈 | 显示后端提示，保持有效身份，不自动重试写入 |
| 退出失败 | 私人内容仍清除，明确显示未确认，可重试退出 |
| 真实表单错误 | 错误密码 401 与重复注册 409 提示正确，密码清空 |
| 外层响应错误 | `code` 与 HTTP 状态不一致时拒绝解析，恢复后可重试 |

本轮未改动后端源码，未重复执行后端完整 Maven 测试；后端原有测试结果见后端验收记录。本机联调启动时曾遇到端口占用与沙箱连接限制，改用独立空闲端口后完成全部检查，没有停止其他已有服务。

## 验收入口

界面截图：[登录页](../docs/验收/阶段二前端-登录.png)、[我的地图](../docs/验收/阶段二前端-我的地图.png)。截图位于被 Git 忽略的本地附件目录，使用隔离测试账号和地图。

按 [README](README.md) 启动已配置的后端和前端：

1. 选择南京，点“我的地图”，进入注册流程；分别以邮箱与手机号注册两个账号。
2. 登录后创建地图，刷新确认仍存在；修改名称并核对列表和标题。
3. 公开地图，用另一个浏览器作为访客刷新城市列表后打开；切回私人，再刷新该浏览器，确认拒绝访问。
4. 在地图详情页退出，确认个人列表、图钉与管理表单清除；通过登录入口再次打开原地图。
5. 使用实际可用的管理员账号核验公共地图名称维护和私人地图隔离。

## 待解决与范围限制

- 远程 PostgreSQL 16 的头像／状态增量、专用应用账号授权和真实业务库联调仍待完成；本机结果不代替远程联调，既有管理员密码未核验。
- 新地图暂无图钉编辑能力，本阶段只管理地图元数据；新增、移动、删除图钉及攻略出处留在阶段三。
- 其他浏览器的变更需刷新重新读取，没有实时推送；前台长时间静止时不轮询会话，重新聚焦／可见或受保护请求时检查。
- 地图分包约 1.123 MB，仍有超过 500 kB 的既有构建提示；手机端、第二个城市与大量图钉不在本轮范围。
- 本轮开发侧验证不代表用户已验收通过。
