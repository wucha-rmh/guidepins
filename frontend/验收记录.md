## 已有验证结论

| 日期 | 检查范围 | 结果 |
| --- | --- | --- |
| 2026-11-24 | 类型与构建 | `npm run build` 通过，包含类型检查；地图分包仍有体积提示 |
| 2026-11-24 | 真实主流程 | 南京目录、公共地图、3 个图钉、侧栏与气泡联动正常 |
| 2026-11-24 | 桌面布局 | 1100 × 800、1280 × 800、1440 × 900 无横向溢出，控件不重叠，气泡位于画布内 |
| 2026-11-24 | 首页边界 | 多城市与长名称、空目录、503 后重试恢复通过；空目录不显示城市计数 |
| 2026-11-24 | 键盘 | 跳到主内容保持 Hash，城市入口可键盘激活；气泡关闭与 Escape 清除选中，关闭后焦点回地图 |
| 2026-11-24 | 图钉与气泡 | 编号一致，长标题和说明可滚动，同坐标地点可从侧栏切换，无说明时省略说明；接口文本按纯文本显示 |
| 2026-11-24 | 资源清理 | 关闭公共地图移除地点和气泡，离开页面移除画布，重新进入可恢复资源 |
| 2026-11-23 | 路由与异常资源 | 刷新、前进后退、直接打开、未知城市／地图／路径、非法地图 ID 的提示与返回入口通过 |
| 2026-11-23 | 接口边界 | 地图列表与详情的空数据、格式错误、503、15 秒超时及恢复重试通过 |
| 2026-11-23 | 底图边界 | Range 返回 206，404、20 秒超时与恢复重试通过；生产预览可加载 Worker 与底图 |
| 2026-11-24 | 页面日志 | 本轮读取的真实页面 error／warn 日志为空 |

主流程使用真实服务，边界场景使用本机临时响应副本，没有修改数据库或地图归档。界面更新后未全面重跑 2026-11-23 的故障场景，也未重新制造 WebGL 丢失；这些历史结果不视为最新版本的完整回归。未新增前端单元测试。
