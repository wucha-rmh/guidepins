## 二、阶段二：登录与私人地图

### 交付

- 邮箱／手机号注册登录、注册后转登录、内存身份与 Cookie 会话恢复、退出，以及原地图地址回跳。
- 城市内公共地图／我的地图分类、默认私人创建、自动打开新地图、名称修改、公开／私人状态切换。
- 本人地图创建与更新时间展示，时间转换为北京时间；列表排序与后端一致。
- 普通用户对他人公共地图只读；管理员可改他人公共地图名称，无切换他人公开状态的入口；他人私人地图不可访问。
- 统一响应解包与业务校验、同源 Cookie、逐次获取 CSRF、超时和错误反馈、禁止自动重放写请求。
- 退出开始、身份改变、会话过期或恢复失败时清除私人列表和详情，取消并忽略旧读取结果；保留城市底图和可用导航。

### 验证环境与方法

1. 执行 `npm run build`，包含 `vue-tsc --noEmit` 与 Vite 生产构建。
2. 创建仅监听 `127.0.0.1` 的独立 PostgreSQL 18.6 临时实例，数据库固定为 `guidepins_frontend_test`。使用仓库现有测试建表文件和最小授权应用账号运行真实后端 JAR。
3. 使用构建预览、真实后端、南京 PMTiles 和 Edge 无头浏览器，建立互相独立的两个普通账号、管理员及访客浏览器上下文。
4. 注册、登录、创建、改名、状态切换及权限拒绝调用真实接口。管理员角色与样例图钉只在隔离库中准备；故障及延迟响应通过测试浏览器路由拦截模拟。
5. 脚本、日志和结果保存在被 Git 忽略的 `backed/target/frontend-stage-two`。没有读取本地 `.env`，没有连接远程业务库。

### 手工验收步骤

按 [README](README.md) 启动已配置的后端和前端：

1. 选择南京，点“我的地图”，进入注册流程；分别以邮箱与手机号注册两个账号。
2. 登录后创建地图，刷新确认仍存在；修改名称并核对列表和标题。
3. 公开地图，用另一个浏览器作为访客刷新城市列表后打开；切回私人，再刷新该浏览器，确认拒绝访问。
4. 在地图详情页退出，确认个人列表、图钉与管理表单清除；通过登录入口再次打开原地图。
5. 使用实际可用的管理员账号核验公共地图名称维护和私人地图隔离。

## 三、个人中心与侧栏收纳

### 交付范围

统一登录注册页：

- 统一入口为 `/#/auth`，默认登录，通过同页“登录／注册”按钮切换；当前模式记录在 URL 查询参数中，刷新可恢复。
- 切换模式保留账号和标识类型，清空密码及旧反馈；注册成功切回登录，保留账号，不自动登录。
- 原 `/#/login` 和 `/#/register` 自动跳转到对应模式，保留原地图回跳参数。
- 登录后返回原城市或地图；从个人地图选城流程进入时保留选城意图，拒绝外部回跳地址。

圆形个人中心：

- 导航右上角只保留一个圆形入口，点击打开个人菜单；邮箱账号使用首字母，其他情况使用用户线框图标。
- 访客菜单提供“登录 / 注册”。登录后显示账号与角色，提供“我的地图”和“退出登录”。
- 菜单项在 `components/AccountMenu.vue` 内集中声明，后续添加个人功能时可在同处增加入口，不需要继续扩充全站导航模板。
- 当前城市内进入我的地图；还没选城市时先回城市目录，再携带个人列表意图进入选中的城市。
- 点击外部或 Tab 移出关闭；Escape 关闭并将焦点返回圆形按钮；向下方向键可进入首个操作。链接与按钮保留原生键盘语义。
- 加载中显示登录恢复状态；恢复失败提供重新检查和退出重试，不显示旧身份的个人功能。

城市侧栏收纳：

- 左侧完整面板默认展开，边缘箭头按钮可收起／展开；收起后保留展开入口，地图使用释放的 304px 空间。

- 使用现有 `ResizeObserver` 调整地图尺寸，不重新创建地图，也不因收纳重新请求详情或个人列表。
- 从个人菜单选择“我的地图”时展开面板，即使已经处于同一地址也生效。切换城市后展开。
- 按钮支持 Enter 和 Space，暴露 `aria-expanded` 与受控侧栏关系；隐藏内容不进入键盘 Tab 顺序。

## 四、手机号区号选择

### 交付

- 选择手机号时，显示国家／地区码下拉框和独立号码输入，默认“中国 +86”。
- 区号选项显示名称与区号。地区作为独立选项标识，共享 +1 等区号的地区不会互相覆盖。
- 登录与注册模式切换、注册成功转回登录时保留所选区号及号码；密码继续清空。
- 提交时将区号和号码组合成后端已有的完整格式，例如 `+86` 与 `13800000000` 组合为 `+8613800000000`。
- 粘贴以 `+` 开头且包含当前所选区号的完整号码时，只使用一份区号；与当前选择不一致时明确提示修正。
- 输入只允许号码数字，完整号码的数字总数保持后端现有 2～15 位约定。超长输入保留原值并提示错误，不静默截断。
- 原生下拉支持方向键和 Tab，手机号使用数字键盘提示，邮箱输入保持独立。

## 五、阶段四第 1 小步：南京离线下载

南京地图详情侧栏新增下载入口。访客可下载公共地图，登录用户可下载自己的私人地图；生成中禁止重复点击，错误显示后端提示。请求最长等待 120 秒，关闭地图、退出或身份检查变化后取消并忽略旧下载。下载为自包含 HTML，可在 Windows Edge／Chrome 直接打开。

离线文件保存地图、图钉、说明、攻略正文、来源链接和站序；全市保留 z7～12，图钉周边约 2 公里保留 z13～16，重叠瓦片去重。复用底图样式，脚本和 Worker 内置压缩，读取内容不依赖第三方网络。虚线标出实际详细瓦片覆盖边界；区域外保留概况，原文链接需要联网。

`npm run build` 的类型检查、查看器打包和生产构建通过。独立 PostgreSQL、最小授权账号上的后端完整验证 40 项全部通过、无跳过。真实 JAR、生产预览和南京底图上的网站下载、双击去重、503 提示、关图／退出后丢弃迟到私人文件通过。Edge、Chrome 分别在断网上下文中直接打开本地文件，地点与攻略联动、站序、全市视图、刷新和空地图通过；未观察到外部 HTTP 请求、脚本或控制台错误。

三地点（夫子庙、新街口、玄武湖）样包约 7.4 MB，较 35.7 MB 原始底图减少约 79.2%；空地图约 5.0 MB。结果随地点分布变化，不承诺固定体积。原始结果、样包、截图和日志在忽略目录 `backed/target/offline-browser-*`；复现脚本、构建顺序和后端权限说明见[南京离线说明](../backed/docs/阶段四南京离线地图.md)。本轮没有连接业务数据库，没有数据库迁移，待用户验收。

手工验收：打开南京地图，滚动至侧栏底部下载；关闭网站并断网，用 Edge 或 Chrome 双击文件，核对地点、攻略、站序、全市缩放及范围外概况。用两个账号分别核对私人下载权限。
